# Vídeo da página

O vídeo é carregado pelo nome do arquivo — basta soltar o arquivo aqui com o
nome esperado, nenhuma alteração de código é necessária. Enquanto o arquivo
não existir, a página exibe um painel sóbrio com um ícone de play no lugar de
um player quebrado.

| Arquivo               | Onde aparece                                              |
| ---------------------- | ---------------------------------------------------------- |
| `apresentacao.mp4`     | Logo abaixo do hero, seção "Um método construído a partir da prática" |

Formato recomendado: `.mp4` (H.264), leve o suficiente para carregar bem —
mire abaixo de 30 MB. O pôster exibido antes do play é a própria foto do
retrato (`/images/moises-retrato.jpg`); troque em `src/components/sections/Disciplines.tsx`
se preferir outra imagem de capa.
